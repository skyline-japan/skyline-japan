このビルについて

駅の上に街を重ねた立体都市。最上部のTOKYO NODEは文化とビジネスをつなぐ。

ホテルに泊まらず高層階へ行くなら、49階のレストランまたは45階のTOKYO NODE DININGを利用できます。展覧会の観覧とレストラン利用はそれぞれ別の予約・料金体系です。

49階のKEI Collection PARISはグリルガストロノミーのレストラン。45階のTOKYO NODE DININGはイベント前後のカフェからディナーまで使えるオールデイダイニングです。

公式案内・予約 ↗
一般来館の補足

45階TOKYO NODE DININGは飲食利用。45～48階の展示等は各イベントの入場券・営業時間に従います。49階SKY GARDEN & POOLは貸切イベント等の条件付きで、自由開放の屋上展望台ではありません。

ホテル宿泊で利用できる範囲

ホテル虎ノ門ヒルズは1階・11～14階。宿泊で利用するのは予約客室等のホテル区域（11階にザ・ラウンジ）です。宿泊しても45～49階TOKYO NODEに自由入場できるわけではありません。

利用条件の確認：2026年10月19日。客室階の希望や眺望席の指定は予約時に確認してください。
